# Stuffy Karts

**Stuffy Karts** is a small adult-humor kart-combat prototype built with Java and jMonkeyEngine.

The core mechanic is **Burden**: attacks can lodge in a kart instead of behaving like ordinary hit points. Accumulated Burden progressively hurts performance until the racer expels it, turning stored disadvantage into a rear attack and forward boost.

> Everything should have a defensible racing or engineering interpretation until context betrays it.

## Project layout

- `game/` — shared jMonkeyEngine game code
- `desktop/` — desktop launcher
- `app/` — Android launcher
- `docs/` — design documents

## Requirements

- JDK 17
- Gradle 9.6+ (9.7 recommended)
- Android SDK 36 for the Android app

## Run

Desktop:

```bash
gradle :desktop:run
```

Android debug APK:

```bash
gradle :app:assembleDebug
```

## Gradle wrapper

The broken partial wrapper generated by the original mobile scaffold was intentionally removed. Once Gradle is available locally, generate a clean wrapper with:

```bash
gradle wrapper --gradle-version 9.7.0
```

Commit the generated `gradlew`, `gradlew.bat`, and `gradle/wrapper/` files afterward.
